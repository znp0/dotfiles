# Zen Browser

Set values for these configs in `about:config`:

| Config | Value | Note |
| --- | --- | --- |
| zen.view.experimental-no-window-controls | true | Prevent the toolbar from being expanded on hover. Need to set `Bookmarks Toolbar` to `Never Show` by hitting `Ctrl+Shift+B` first. |
| zen.workspaces.scroll-modifier-key | `ctrl` | Delete the current value to allow scrolling to cycle through workspaces while hovering on the sidebar without pressing any modifier key. |
| full-screen-api.warning.timeout | 0 | Disable the pop-up message when entering full screen, like "YouTube now uses full screen". |
| accessibility.typeaheadfind | false | Disable opening Find automatically when typing a character. |
| dom.webgpu.enabled | true | Enable WebGPU. |
